# container-runtime Specification

## Purpose
定義應用程式容器映像的組成與執行方式，使開發、預備與正式環境能以相同的映像重現，並保證映像不含機密、不以管理員身分執行、不使用開發用伺服器。

## Requirements

### Requirement: 容器使用正式用伺服器
容器 SHALL 以多執行緒的正式 Web 伺服器執行應用程式，SHALL NOT 使用框架內建的開發伺服器。

#### Scenario: 啟動容器
- **WHEN** 啟動容器
- **THEN** 主行程為正式 Web 伺服器，且啟動訊息中沒有開發伺服器的警告

### Requirement: 容器以非管理員身分執行
容器內的應用程式 SHALL 以非 root 使用者執行。

#### Scenario: 檢查執行身分
- **WHEN** 在執行中的容器內查詢應用程式行程的使用者
- **THEN** 使用者不是 root

### Requirement: 映像不含機密與開發檔案
映像 SHALL NOT 包含 `.env`、版本控制目錄、測試資料與任何機密；SHALL 包含本機前端資產與字型。

#### Scenario: 檢查映像內容
- **WHEN** 列出映像檔案系統
- **THEN** 找不到 `.env` 與版本控制目錄，並找到前端資產與字型檔

#### Scenario: 建置不帶入機密
- **WHEN** 專案根目錄存在 `.env` 並建置映像
- **THEN** `.env` 不會出現在映像的任何一層

### Requirement: 執行環境版本固定
映像的語言執行環境版本 SHALL 與本機開發使用的主要與次要版本一致，並在映像定義中固定，避免開發與部署環境差異。

#### Scenario: 版本一致
- **WHEN** 比較映像內與本機開發環境的語言執行環境版本
- **THEN** 主要與次要版本相同

### Requirement: 容器以環境變數取得設定且缺漏即結束
容器 SHALL 在啟動時從環境變數取得所有設定與機密。必要機密缺漏時，容器 SHALL 以非零結束碼結束，而不是帶著錯誤設定持續運行。

#### Scenario: 缺少必要機密
- **WHEN** 以 `APP_ENV=production` 啟動容器但未提供必要機密
- **THEN** 容器在啟動階段結束並回傳非零結束碼，輸出只列出缺漏的變數名稱

#### Scenario: 提供完整設定
- **WHEN** 以完整的設定啟動容器
- **THEN** 容器啟動成功，就緒檢查在資料庫可用時回應 200

### Requirement: 容器可被平台正常停止
容器 SHALL 在收到終止訊號時停止接收新請求、完成進行中的請求後結束。

#### Scenario: 收到終止訊號
- **WHEN** 向執行中的容器送出終止訊號
- **THEN** 進行中的請求完成，容器在合理時間內正常結束
