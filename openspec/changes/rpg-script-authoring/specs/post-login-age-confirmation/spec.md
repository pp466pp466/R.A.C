# Spec Delta

## MODIFIED Requirements

### Requirement: 補填年齡確認
待確認年齡的玩家 SHALL 能透過需要登入的 API 提交生日（`YYYY-MM-DD`）、年齡區間（列舉選項）與暱稱（規則見 `player-nickname`），三者為同一個步驟、同一次提交，全有或全無。成功時 SHALL 記錄生日、年齡區間、暱稱、確認時間與年齡規則版本、清除期限，並讓玩家回到登入前要去的位置（不合法時為預設頁面）。已完成的帳號再次提交 SHALL 成功且不改變原本的紀錄（含暱稱）。

#### Scenario: 補填成功
- **WHEN** 待確認年齡的玩家提交一致的生日與年齡區間，以及合格的暱稱
- **THEN** 記錄年齡資料與暱稱並清除期限，之後可使用全部功能

#### Scenario: 重複提交
- **WHEN** 已完成的玩家再次提交不同的內容
- **THEN** 回應成功，原本的紀錄不變

#### Scenario: 暱稱不合格時整個步驟不保存
- **WHEN** 待確認年齡的玩家提交一致的生日與區間，但暱稱不合格
- **THEN** 回應暱稱欄位的錯誤，生日、區間與暱稱都沒有保存，期限不變

#### Scenario: 缺少暱稱
- **WHEN** 待確認年齡的玩家提交時沒有暱稱
- **THEN** 回應暱稱必填的錯誤，沒有保存任何資料
