# Spec Delta

## ADDED Requirements

### Requirement: 預備環境壓測使用隔離的壓測服務
在雲端量測容量時，負載測試 SHALL 針對隔離的壓測服務（deployment-plan 的壓測環境）執行，SHALL NOT 針對預備環境本身或使用真實模型供應商的服務：該服務使用真實的應用程式映像與真實的 Gemini 轉接器，但模型端點是假模型伺服器，因此不消耗任何額度。測試開始前，腳本 SHALL 確認目標網址對應壓測服務（以主機名稱的壓測標記判斷），否則拒絕。

#### Scenario: 壓測服務
- **WHEN** 目標網址的主機名稱含壓測標記
- **THEN** 腳本接受（仍需要遠端確認參數）

#### Scenario: 拒絕預備環境本身
- **WHEN** 目標是預備環境的服務網址（不含壓測標記）
- **THEN** 腳本拒絕並說明壓測必須針對隔離的壓測服務

### Requirement: CPU 使用率由雲端監控取得
判定所需的 CPU 使用率 SHALL 能由雲端監控自動取得：腳本取壓測期間該服務 CPU 使用率的最大值（以第 95 百分位的時間序列為準），並以此作為判定的輸入；無法取得（沒有權限、沒有資料）時 SHALL 標為未驗證，SHALL NOT 以預設值代替。取得的數字 SHALL 只含彙總值，不含其他資源的資訊。

#### Scenario: 取得 CPU
- **WHEN** 壓測結束後指定測試的起訖時間
- **THEN** 判定使用雲端監控回報的 CPU 數字

#### Scenario: 取不到
- **WHEN** 雲端監控沒有該時段的資料
- **THEN** CPU 標為未驗證，整體不判為通過
