# Spec Delta

## ADDED Requirements

### Requirement: 告警在預備環境各演練一次並留下證據
六類平台告警（5xx 比率、服務存活、服務就緒、寄信失敗、排程工作失敗、告警檢查停擺）建立之後，每一類 SHALL 在預備環境以可逆的方式觸發至少一次，並記錄證據：觸發方式、觸發時間、收到通知的時間，以及復原的方式與時間。演練 SHALL 只在預備環境進行（SHALL NOT 對正式環境演練），且每一種觸發方式 SHALL 在演練前載明如何復原。沒有實際收到通知的類別 SHALL 標為未驗證，且 SHALL NOT 讓該告警被視為已驗證。

#### Scenario: 排程工作失敗
- **WHEN** 以會失敗的參數執行一次排程工作
- **THEN** 在窗口內收到「排程工作失敗」的電子郵件，紀錄載明時間

#### Scenario: 告警檢查停擺
- **WHEN** 暫停 `check-alerts` 的排程超過停擺門檻
- **THEN** 收到「告警檢查停擺」的通知；恢復排程後告警自動解除

#### Scenario: 就緒失敗
- **WHEN** 暫時讓預備環境的資料庫連線無效並持續超過探測門檻
- **THEN** 收到就緒告警且通知標明資料庫，復原後告警解除

#### Scenario: 沒收到就不算驗證
- **WHEN** 某類告警觸發後在預期窗口內沒有收到通知
- **THEN** 紀錄標為未驗證並記錄推測的原因，不以預期結果代替

#### Scenario: 不對正式環境演練
- **WHEN** 檢視演練的步驟與腳本
- **THEN** 目標只有預備環境，正式環境的資源不在其中
