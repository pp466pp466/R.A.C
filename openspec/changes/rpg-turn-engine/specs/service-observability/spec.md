# Spec Delta

## ADDED Requirements

### Requirement: RPG 回合與第 0 幕事件只含白名單欄位
RPG 回合引擎的日誌事件（回合開始、完成、被擋、中斷、失敗、狀態呼叫失敗、結局，以及第 0 幕的開始、完成、退回與接手）SHALL 只含：事件名稱、`user_id`（內部整數）、存檔的內部整數編號、輪數與嘗試序號、整數的字數與延遲與首字時間、固定列舉（結束狀態、結束原因、被擋類別、第 0 幕狀態）、模型名稱與時間；SHALL NOT 含玩家行動、劇情原文、轉場文字、NPC 名稱與特質、地點、目標、第 0 幕、被擋的文字、冪等鍵、存檔對外識別碼、標記字串或任何玩家文字。

#### Scenario: 回合完成事件
- **WHEN** 一個回合完成
- **THEN** 日誌有一筆回合完成事件，只含上述白名單欄位

#### Scenario: 被擋事件
- **WHEN** 一個回合被擋
- **THEN** 日誌事件含被擋類別的列舉，沒有被擋的文字

#### Scenario: 日誌掃描
- **WHEN** 走過一個完整回合、一個被擋回合、一個中斷回合與第 0 幕後掃描全部日誌輸出
- **THEN** 找不到行動、劇情、NPC 名稱、地點、第 0 幕、被擋文字、冪等鍵與標記字串
