# Spec Delta

## MODIFIED Requirements

### Requirement: RPG 回合與第 0 幕事件只含白名單欄位
RPG 回合引擎的日誌事件（回合開始、完成、被擋、中斷、失敗、狀態呼叫失敗、結局，第 0 幕的開始、完成、退回與接手，以及記事簿的抓取完成、跳過、放棄與失敗、玩家儲存成功與被拒）SHALL 只含：事件名稱、`user_id`（內部整數）、存檔的內部整數編號、輪數與嘗試序號、整數的字數、條數、最長一條的字數、版本與延遲與首字時間、固定列舉（結束狀態、結束原因、被擋類別、第 0 幕狀態、記事簿事件的結果與原因）、模型名稱與時間；SHALL NOT 含玩家行動、劇情原文、轉場文字、NPC 名稱與特質、地點、目標、第 0 幕、記事簿的任何文字、被擋的文字、冪等鍵、存檔對外識別碼、標記字串或任何玩家文字。

#### Scenario: 回合完成事件
- **WHEN** 一個回合完成
- **THEN** 日誌有一筆回合完成事件，只含上述白名單欄位

#### Scenario: 被擋事件
- **WHEN** 一個回合被擋
- **THEN** 日誌事件含被擋類別的列舉，沒有被擋的文字

#### Scenario: 日誌掃描
- **WHEN** 走過一個完整回合、一個被擋回合、一個中斷回合與第 0 幕後掃描全部日誌輸出
- **THEN** 找不到行動、劇情、NPC 名稱、地點、第 0 幕、被擋文字、冪等鍵與標記字串

#### Scenario: 記事簿抓取事件
- **WHEN** 一次記事簿抓取完成、跳過或放棄
- **THEN** 日誌有一筆對應事件，只含整數（條數、最長一條的字數、追加後的字數、版本）與結果或原因的列舉，沒有任何條目文字

#### Scenario: 記事簿日誌掃描
- **WHEN** 走過一次 AI 追加、一次玩家儲存與一次被規則層拒絕的儲存後掃描全部日誌輸出
- **THEN** 找不到任何記事簿的文字，也找不到被拒絕的內容
