# Proposal

## Why

後端的 RPG 已經齊備（開存檔、第 0 幕、回合串流、世界狀態、記事簿、遊戲幣與簽到都已封存），RC-3a `rpg-entry-ui` 也讓玩家能從 `/game` 選劇本、建主角並開出存檔——但按下「開始冒險」之後落在 `/game/<存檔識別碼>` 的**空殼**，寫著「劇情畫面建置中」。目前沒有任何畫面能讓人親手玩一輪、看到串流與打字機、看見餘額被扣，也沒有辦法檢視或編輯記事簿。

RC-3 探索（`docs/RPG.md` 7.17）已決定把遊戲主畫面獨立成 RC-3b。使用者也要求「開始冒險」之後直接進聊天、不必再點「我的存檔」——精靈已導向 `/game/<存檔>`，本 change 把該網址的空殼換成真正的遊戲主畫面即滿足。

## What Changes

- **遊戲主畫面**取代 `/game/<存檔識別碼>` 的空殼（`session.html` 整頁取代）：頂列（劇本標題、內容模式、遊戲幣餘額、回到冒險）、劇情時間軸（第 0 幕＋逐輪的玩家行動與 AI 回應）、行動輸入框、世界狀態面板（地點、經過月數、目標、去過的地點、主角年齡）、記事簿面板。手機寬度下面板以覆蓋方式開關。已完結的存檔仍可閱讀但不可送出。
- **串流接收與打字機**：以瀏覽器原生 `fetch` 搭配 `ReadableStream` 接 `POST /api/game/sessions/<id>/turns/stream` 與 `…/opening/stream`；自寫 SSE 解析（`meta`／`token`／`ping`／`transition`／`state`／`done`／`error`），片段文字交給既有的 `UI.TypewriterBuffer` 逐字渲染；任何收到的位元組重設閒置計時器（45 秒），總逾時 180 秒，`AbortController` 在逾時、取消與離開頁面時中止；`done` 是完整接收的唯一依據，無論成功、失敗或中斷皆在 `finally` 恢復輸入。被擋回合：丟棄未完成的氣泡、換成一行轉場文字；`will_retry` 為假時解鎖輸入並請玩家換個行動。
- **第 0 幕與歷史補齊**：載入時讀存檔快照；第 0 幕尚未完成者自動呼叫開場串流（另一個裝置正在生成時等待），已完成者直接顯示、不重抽；歷史以 `since_seq` 增量補齊並以後端為準。
- **遊戲幣與簽到入口**：頂列顯示餘額，每輪結束以 `done.coins` 更新；送出前餘額低於每輪幣價時說明，伺服器回 409 `insufficient_coins` 時跳自製 Modal，內含最小的簽到入口（呼叫既有的 `GET /api/wallet` 與 `POST /api/wallet/checkin`，含超過免費幣上限時的預覽與「取消／領取」確認）。
- **IndexedDB 的角色（使用者已確認）**：後端為權威；IndexedDB 只存「離線閱讀快取」（歷史回合、第 0 幕、世界狀態摘要）與**最多一筆在途回合**（`client_msg_id` ＋行動文字），重新整理或斷線後以同一個 `client_msg_id` 冪等重送（已完成則重播、不重複扣幣）；**不做自動排隊重送**（每輪都花遊戲幣）。資料庫名稱含使用者的對外識別碼；暫存不可用時退回記憶體。
- **記事簿面板**（最後一批）：檢視全文與用量（如「1800 / 2000」）、已滿提示（說明之後的設定不再被記住、AI 可能遺忘）、編輯與儲存（長度不得超過容量、`notebook_version` 衝突時以後端為準並更新畫面、規則層命中只顯示類別、已完結不可編輯）。內容一律純文字渲染。
- **入口頁的預設分頁（使用者已確認）**：`/game` 在玩家已有存檔時先顯示「我的存檔」，沒有存檔仍顯示「選劇本」。
- 全程使用既有後端；Vue 3 全域變數模式、離線資源、自製 Modal 與 Toast、純文字渲染（嚴禁 `v-html`）、`data-bs-*` 與 Bootstrap JavaScript 不使用。**沒有遷移、沒有新環境變數、沒有新日誌事件、不改任何遊戲規則、審查、額度或資料表。**

## Capabilities

### New Capabilities

- `rpg-game-screen`：`/game/<存檔識別碼>` 遊戲主畫面的外殼與初始狀態、載入順序（快照 → 第 0 幕 → 歷史）、劇情時間軸與行動輸入、世界狀態面板、已完結與內容模式／閘門提示、前端離線與狀態接管、手機版面。
- `rpg-stream-client`：RPG 串流的前端接收協定——`fetch`＋`ReadableStream` 的 SSE 解析、事件處理、閒置與總逾時、`AbortController`、`done` 為結束標記、`finally` 恢復、被擋與轉場、錯誤與 409／429／503 對照、打字機接線、不顯示結構化原文。
- `rpg-game-sync`：RPG 的本機暫存與同步——IndexedDB 離線閱讀快取、單筆在途回合與冪等重送、`since_seq` 增量補齊、後端為準、暫存不可用時退回記憶體、帳號隔離。
- `rpg-wallet-ui`：遊戲畫面內的遊戲幣——餘額顯示與更新、餘額不足的處理、最小簽到入口（預覽、超過上限的確認、已簽到）。
- `rpg-notebook-panel`：記事簿面板——檢視、用量與已滿提示、編輯與儲存、版本衝突、錯誤對照、已完結唯讀、純文字渲染。

### Modified Capabilities

- `rpg-entry-pages`：移除「存檔頁的空殼」需求（由 `rpg-game-screen` 取代）；「選劇本與我的存檔兩個分頁」的預設分頁改為「有存檔先顯示我的存檔」。

## Impact

- **程式**：`app/controllers/game_page_controller.py`（`/game/<存檔>` 改為渲染遊戲畫面並傳入初始狀態：會員等級、閘門、存檔摘要、串流逾時；非擁有者仍同一個 404）、`app/templates/game/session.html`（整頁取代）；前端新增 `app/static/js/game/` 的串流／SSE 解析、遊戲狀態純函式、本機暫存與同步、遊戲掛載、錢包 Modal、記事簿面板等模組，`game.css` 擴充，`entry.js` 改預設分頁；`GameEntryService.session_summary` 視需要擴充（不影響既有契約）。
- **測試**：Node 單元測試（SSE 解析、事件狀態機、同步、記事簿與錢包純函式，`vm` 沙盒掛載）；`tests/test_game_pages.py` 的存檔頁案例改寫；新增伺服器端到端整合測試（假模型，沿用 `test_rpg_flow` 夾具，驗證頁面載入所需的端點序列與日誌掃描）；`tests/architecture/test_frontend_rules.py` 守門。
- **資料庫**：無。**部署**：無順序限制；沒有新環境變數。
- **文件**：`docs/前端結構-frontend.md`、`docs/系統架構-architecture.md`、`docs/RPG.md` 7.17、`docs/路線圖-roadmap.md`，依 `docs/README.md` 對照表；README 頁面說明與驗收紀錄。
- **不涉及**：AGENTS.md（規則已寫明）、LLM 提示詞、遊戲幣規則與額度、日誌白名單。
- **不做**：玩家重新生成與編輯輸入的按鈕（RC-2c，排在本 change 之後）；錢包記錄頁與儲值／訂閱（W2）；完整目錄與搜尋（RC-8）；刪除或封存存檔的介面；「我的存檔」顯示最後一幕摘要或封面；圖片與頭像；分級切換與年齡確認提示以外的帳號設定；自動排隊重送。
