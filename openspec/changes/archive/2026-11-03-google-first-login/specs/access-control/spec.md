# Spec Delta

## MODIFIED Requirements

### Requirement: 受限登入狀態預設拒絕
受限登入狀態 SHALL 預設拒絕：只有明確列入允許清單的端點能接受它。受限登入狀態有三種，各有自己的允許清單與拒絕代碼：①等待刪除（`account_deletion_pending`）——查詢自己、撤銷刪除、登出與 `/account`；②待確認年齡（`age_confirmation_required`）——查詢自己、提交年齡確認、登出與 `/age`；③被鎖定（`account_locked`）——查詢自己、申訴的提交與查看、登出與 `/appeal`。同時符合多種時，被鎖定優先於待確認年齡，待確認年齡優先於等待刪除。新增的需要登入的端點若沒有明確允許，SHALL 自動拒絕所有受限狀態（API 回 403 與該狀態的代碼，頁面導向該狀態的頁面），且 SHALL 有自動化測試掃描所有需要登入的端點、對三種狀態各證明一次。管理員帳號 SHALL NOT 進入待確認年齡的受限狀態。

#### Scenario: 允許清單以外的端點
- **WHEN** 測試以三種受限登入狀態各自逐一呼叫所有需要登入的 API
- **THEN** 各自允許清單以外的端點全部回應 403 與該狀態的代碼

#### Scenario: 新增端點
- **WHEN** 開發者新增一個需要登入的端點而未列入允許清單
- **THEN** 該端點對三種受限狀態同樣回應 403

#### Scenario: 同時被鎖定且待確認年齡
- **WHEN** 待確認年齡的玩家因補填不一致達門檻而被鎖定
- **THEN** 其受限狀態為被鎖定（回 `account_locked`），解除後才回到待確認年齡
