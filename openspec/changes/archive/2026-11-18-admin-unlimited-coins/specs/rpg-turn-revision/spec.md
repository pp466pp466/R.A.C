# Spec Delta

## MODIFIED Requirements

### Requirement: 重新生成與編輯共用的免費次數與費用
每個回合前 N 次修訂（重新生成與編輯合計）SHALL 免費（N 由設定表現讀，初始 2），第 N+1 次起每次消耗一輪的幣價（現讀自設定表，初始 30；編輯時原本那輪已扣的幣不退）。次數 SHALL 以成功替換為準：成功的重新生成與成功的編輯都使該回合的已用次數加 1，編輯不使次數歸零；失敗、中斷、被擋不加。免費的修訂 SHALL NOT 預扣，也 SHALL NOT 檢查餘額；付費者 SHALL 在認領的同一個交易內預扣，餘額不足 SHALL 回 409 `insufficient_coins` 且不認領。**管理員帳號（角色為 admin 且啟用中）的免費次數照常計數，但超過免費次數後的預扣金額為 0，SHALL NOT 因餘額不足被拒絕；`last_turn` 的 `regenerate_cost` 與 `edit_cost` 對管理員 SHALL 一律為 0。**

#### Scenario: 前兩次免費
- **WHEN** 玩家對同一回合依序重新生成一次、編輯一次（或任意兩次重新生成與編輯的組合）
- **THEN** 兩次都不扣遊戲幣，帳本沒有新的預扣紀錄

#### Scenario: 第三次付費
- **WHEN** 玩家對同一回合第 3 次修訂（重新生成或編輯）且餘額足夠
- **THEN** 預扣一輪的幣價，成功後結算

#### Scenario: 免費次數內餘額不足仍可修訂
- **WHEN** 玩家的遊戲幣餘額低於一輪的幣價，但該回合還有免費次數
- **THEN** 重新生成與編輯都可以進行，不扣幣

#### Scenario: 付費但餘額不足
- **WHEN** 第 3 次修訂時餘額不足
- **THEN** 回 409 `insufficient_coins`，回合沒有被認領、已用次數不變

#### Scenario: 失敗不消耗免費次數
- **WHEN** 一次免費的重新生成或編輯被擋、中斷或失敗
- **THEN** 該回合的已用次數不變，下次仍是免費

#### Scenario: 編輯不使次數歸零
- **WHEN** 已用完免費次數的回合被編輯並成功（付費）
- **THEN** 已用次數加 1 而不是歸零，之後的重新生成與編輯仍須付費

#### Scenario: 餘額為 0 的管理員超過免費次數
- **WHEN** 餘額為 0 的管理員對同一回合第 3 次修訂
- **THEN** 修訂照常進行，帳本有一筆金額為 0 的預扣並在成功後結算，已用次數加 1，沒有 `insufficient_coins`

#### Scenario: 管理員的修訂費用為 0
- **WHEN** 管理員取得存檔快照中最後一輪的修訂資訊
- **THEN** `regenerate_cost` 與 `edit_cost` 都是 0；剩餘免費次數 `free_left` 仍照實回報
