# Spec Delta

## MODIFIED Requirements

### Requirement: 每次呼叫都寫入用量帳本
系統 SHALL 為每一次對模型供應商的呼叫寫入一筆帳本紀錄：使用者與對話（可為空）、用途（對話、摘要、劇本審查、主角生成或主角審查）、供應商與實際使用的模型、第幾次嘗試、結果狀態、輸入／輸出／思考 token、延遲、結束原因。帳本 SHALL NOT 保存對話全文。

#### Scenario: 一則訊息呼叫了兩次
- **WHEN** 主要模型逾時後以備援成功
- **THEN** 帳本有兩筆：第一筆為逾時、模型為主要模型；第二筆為成功、模型為備援模型

#### Scenario: 帳本不含對話內容
- **WHEN** 檢查帳本所有欄位
- **THEN** 其中沒有使用者訊息、回覆或摘要的文字

#### Scenario: 主角相關的用途
- **WHEN** 完成一次主角生成與一次主角審查
- **THEN** 帳本分別有用途為 `protagonist_gen` 與 `protagonist_review` 的紀錄，且沒有任何自我介紹或角色卡的文字
