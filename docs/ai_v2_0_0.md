## 主題一：專案概述與總覽 (Project Overview)

本專案旨在建構一個以大型語言模型 (LLM) 驅動的「開放世界聊天式文字冒險遊戲平台」。系統結合動態敘事生成、記憶體讀取與強約束事件錨點，為玩家提供高度自由、無固定走向的 RPG 冒險體驗。

### 核心運作與開發規範 (AGENTS.md 遵循指南)
1. **動態內容生成**：由 AI 根據世界觀設定動態發展故事，不設固定劇情路線。
2. **無縫同步與追蹤**：開發團隊與創作者對話記錄及系統規格維持自動整合與即時同步。
3. **LLM 約束與邊界**：嚴格遵守 AGENTS.md 規範，將 LLM 視為不可信內容生成器，所有輸出需通過強 JSON 驗證與 Service 層驗證後始可存入永久儲存庫。
4. **離線前端架構**：嚴禁使用 CDN，所有第三方庫（Vue 3、Bootstrap 5.3、Axios）一律線下下載至 `static/vendor/` 目錄，以 Flask `url_for` 引入。
5. **視覺風格統一**：採用「極簡黑暗電影／文字雜誌風 (Cinematic Dark Minimalist)」，配色包含劇院深黑 (`#0F1012`)、薄霧灰白 (`#E2E4E9`)、鋼鐵灰 (`#8A8F99`)、導演琥珀橙 (`#FF6B35`) 與 1px 極細金屬邊框 (`#2A2D34`)。
6. **自製 UI 元件**：嚴禁使用外部彈窗套件（如 SweetAlert2），一律以 Vue 3 全域模式搭配 Bootstrap 5.3 自製內建 Modal 與 Toast。
7. **雙軌資料庫抽象**：採用 SQLAlchemy ORM 支援 SQLite 與 SQL Server 雙軌運作，100% 透過純 ORM 抽象模型操作，嚴禁原生 Raw SQL。

## 主題二：技術架構與後端三層設計 (Architecture Spec)

### 1. 技術堆疊表
* **後端框架**：Python 3.10+ / Flask (MVC + Web API 雙 Controller)
* **LLM 引擎**：Google Gemini API (使用 Gemini API Key)
* **資料庫與 ORM**：SQLAlchemy ORM + SQLite + SQL Server (雙軌相容)
  * **SQLite 條件初始化**：僅在底層為 SQLite 時開啟 `PRAGMA journal_mode=WAL;` 預寫日誌模式。
  * **SQL Server 初始化**：若底層為 SQL Server，嚴禁發送 PRAGMA 指令，由連線池與交易機制接管並發與非同步。
* **前端框架**：Vue 3.0 JavaScript (全域變數模式，禁用 `.vue` 元件與 Vite 打包)
* **RWD 框架**：Bootstrap 5.3 (Dark Mode 全域樣式覆蓋)
* **網路通訊**：Axios (離線引入)

### 2. 後端關注點分離 (Separation of Concerns)
* **MVC Page Controller** (`controllers/page_controller.py`)：僅負責渲染基本 HTML 頁面外殼與初始狀態傳遞。
* **Web API Controller** (`controllers/api_controller.py`)：一律回傳 JSON 格式，專門處理 axios 發送的 Ajax 請求。
* **Service 層** (`services/game_service.py`)：負責遊戲核心邏輯、System Prompt 組合、強約束事件錨點驗證以及呼叫 Gemini API。
* **Repository 層** (`repositories/game_repository.py`)：負責 SQLAlchemy CRUD 操作，封裝 ORM Session 釋放、連線生命週期管理與跨資料庫 JSON 序列化轉換。

## 主題三：資料庫 Schema 設計 (Database Schema Spec - SQLAlchemy ORM)

### 1. 使用者資料表 (`users`)
| 欄位名稱 (Field) | 型態 (Type) | 約束 (Constraints) | 說明 (Description) |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 使用者唯一識別碼 |
| `username` | VARCHAR(50) | UNIQUE, NOT NULL | 帳號名稱 |
| `password_hash` | VARCHAR(255) | NOT NULL | 加密密碼 |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 註冊時間 |

### 2. 劇本資料表 (`scripts`)
| 欄位名稱 (Field) | 型態 (Type) | 約束 (Constraints) | 說明 (Description) |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 劇本唯一識別碼 |
| `creator_id` | INTEGER | FOREIGN KEY (users.id) | 創作者 ID |
| `title` | VARCHAR(100) | NOT NULL | 劇本名稱 |
| `world_view` | VARCHAR(50) | NOT NULL | 世界觀類別 (如：古風仙俠) |
| `background_and_system` | TEXT | NOT NULL | 背景與境界體系詳細設定 |
| `characters_json` | JSON | NOT NULL | 重要 NPC 名冊 (含預設好感度與性格) |
| `locations_json` | JSON | NULLABLE | 已知地點清單 |
| `milestones_json` | JSON | NOT NULL | 強約束必觸發事件 (Milestones) |
| `ending_rules` | TEXT | NOT NULL | 結局條件規則 (預設 100 歲老死) |

### 3. 遊戲工作階段 / 玩家存檔表 (`sessions`)
| 欄位名稱 (Field) | 型態 (Type) | 約束 (Constraints) | 說明 (Description) |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 遊戲 Session 唯一識別碼 |
| `user_id` | INTEGER | FOREIGN KEY (users.id) | 玩家 ID |
| `script_id` | INTEGER | FOREIGN KEY (scripts.id) | 對應劇本 ID |
| `player_name` | VARCHAR(50) | NOT NULL | 玩家角色名字 |
| `player_age` | INTEGER | DEFAULT 16 | 當前角色年齡 |
| `current_location` | VARCHAR(100) | NULLABLE | 當前所在地點 |
| `status_summary` | TEXT | NULLABLE | 玩家狀態/修為/裝備摘要 |
| `is_ended` | BOOLEAN | DEFAULT FALSE | 遊戲是否結束 (死亡/老死) |
| `end_reason` | VARCHAR(255) | NULLABLE | 遊戲結束原因 |
| `updated_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 最後遊玩時間 |

### 4. 對話與記憶體紀錄表 (`memory_logs`)
| 欄位名稱 (Field) | 型態 (Type) | 約束 (Constraints) | 說明 (Description) |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 對話紀錄 ID |
| `session_id` | INTEGER | FOREIGN KEY (sessions.id) | 對應遊戲 Session ID |
| `turn_number` | INTEGER | NOT NULL | 對話回合數 |
| `user_action` | TEXT | NOT NULL | 玩家輸入或選擇的行動 |
| `llm_raw_response` | JSON | NOT NULL | LLM 傳回之 JSON (含 NPC 好感度與狀態變更) |
| `memory_summary` | TEXT | NULLABLE | 歷史記憶摘要 (注入 Prompt 用) |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 生成時間 |

## 主題四：首發預設劇本設定 (Default Script Spec - 古風仙俠)

* **世界觀**：古風仙俠
* **故事背景**：乾歷朝 1202 年到 1208 年長達 6 年的正邪大戰落下帷幕，正道聯合對陣邪魔兩教聯合最後正道取得勝利。邪魔兩方幾乎殞落，正道也損失慘重，8 個門派只餘 4 個，其中青雲宗為其中一個存活的正道門派。現在為乾歷朝 1214 年 6 月。
* **修道體系**：入氣 > 練體 > 築基 > 金丹 > 元嬰 > 化神 > 渡劫 > 飛升成仙
* **靈根種類**：五行靈根 (金木水火土)、變異靈根 (冰雷風時空)
* **法寶/靈根品階**：下品、中品、上品、極品 (法寶分為黃階 > 地階 > 天階 > 仙器)
* **重要 NPC**：夏侯傑 (青雲宗宗主，老成沉穩帶點桀傲，口頭禪：「自從正邪大戰後未嘗一敗。」，初始好感度：20)
* **已知地點**：青雲宗
* **必觸發事件 (Milestones)**：乾歷朝 1215 年 11 月青雲宗收徒大典
* **結局設置**：遭遇實力差距過大敵人不逃跑則死亡，無年齡上限。
